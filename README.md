# CSS
Css explain
<br>
The Creators: CSS was proposed by Håkon Wium Lie on October 10, 1994, while he was working with Tim Berners-Lee at CERN. Shortly after, Bert Bos joined him to co-author the specification and became a co-creator.
The Motivation: In the early web, HTML was strictly meant for document structure. However, web authors were desperate to control fonts, colors, and layout. They started misusing HTML tags (like <font> and <table>) for visual design, bloating the code and breaking accessibility. CSS was proposed as a way to cleanly separate content (HTML) from presentation (design).
Other Proposals: Lie's proposal wasn't the only one; proposals like CHSS (Cascading HTML Style Sheets) and SSP (Stream-based Style Sheet Proposal) were floating around, but CSS eventually won out because it allowed multiple style sheets to "cascade" or blend together (e.g., user preferences overriding author styles).
